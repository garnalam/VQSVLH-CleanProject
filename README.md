# Reverse Engineered Project Modules

This package is organized by game module. Each module contains `original/` and `decoded/` folders.

Important modules:
- `modules/source_code`: original class files, CFR decompiled Java, and javap bytecode.
- `modules/event`: original scene files plus decoded scene/room/event JSON.
- `modules/map`: original maps plus decoded layer/tile JSON.
- `modules/script`: original script tables plus decoded matrices/text tables.
- `modules/img` and `modules/tex`: original disguised assets plus decoded PNGs.
- `modules/ui`: original UI binaries plus decoded layout JSON.
- `modules/reports`: global report, inventories, resource call graph, and decode tools.
